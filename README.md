# 💻 Exercícios de Lógica de Programação

## 📝 Descrição do Projeto

Este projeto reúne exercícios desenvolvidos durante os estudos iniciais de lógica de programação no curso de Análise e Desenvolvimento de Sistemas.

As atividades possuem como objetivo praticar estruturas básicas de programação, variáveis, operadores, estruturas condicionais e resolução de problemas por meio de algoritmos.

## 🚀 Tecnologias Utilizadas

* Python
* Visual Studio Code

## 📚 Aprendizados

* Uso de variáveis
* Estruturas condicionais
* Lógica de programação
* Resolução de problemas
